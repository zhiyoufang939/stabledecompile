## Why

当前 WEIKU_C、WEIKU_B、WEIKU_A 在选卡界面中被当成三辆互不相关的植物，既无法表达“威酷”作为同一辆赛车的成长关系，也没有可浏览、可改装并保存升级进度的车辆界面。需要新增一个可扩展的车库与车辆升级模型，让玩家用一张“威酷”卡完成 C→B→A 的战斗内叠种升级，并为以后追加 S 级和其他车辆保留稳定接口。

## What Changes

- 新增从主界面进入的“车库”界面，视觉结构参考赛车车库：中央车辆展示、左上等级与车辆属性、左下基础数值条、右侧升级路径、右下“赛车改装”按钮，以及可爱风格的车辆简介。
- 车库首期只登记一辆车辆家族“威酷”；新档案默认永久解锁 C 级，可依次改装到 B、A，后续允许通过配置追加 S 或增减中间等级。
- 每次车库改装只解锁下一级，消耗界面显示的 500,000 金币；余额不足、已到当前最高等级或前置等级未解锁时不得扣款。升级成功后立即保存玩家档案并刷新车库显示。
- 将车辆、等级顺序、展示数据、战斗 SeedType、数值和升级费用放入集中定义，车库 UI、存档和战斗逻辑通过车辆/等级 ID 查询，不在各处写死 C/B/A 分支。
- **BREAKING（玩法表现）**：普通选卡界面的 WEIKU_C、WEIKU_B、WEIKU_A 三张卡合并为一张名为“威酷”的 100 阳光卡；现有三个 SeedType 保留用于资源、战斗实体和旧存档兼容，但 B/A 不再作为独立普通选卡项。
- 同一张“威酷”卡第一次种植生成 C；将该卡再次种到同格 C 上会花费 100 阳光并替换为 B，再次叠种会替换为 A。允许达到的最高战斗等级受车库永久解锁等级限制；未解锁的下一等级不能叠种。
- 叠种升级复用同一张卡的冷却周期，每次成功种植或升级都正常扣除 100 阳光并使卡片进入冷却；达到已解锁最高等级后，同格继续叠种被拒绝且不扣阳光、不消耗冷却。
- 保留 C/B/A 当前各自的动画、子弹、伤害与攻击节奏，并定义旧用户档案和旧关卡战斗存档的兼容迁移规则。

## Capabilities

### New Capabilities

- `vehicle-garage`: 车辆车库的入口、浏览布局、属性/数值/升级路径/简介展示，以及赛车改装交互。
- `vehicle-progression`: 数据驱动的车辆等级定义、永久解锁进度、金币改装交易、存档版本与兼容迁移。
- `weiku-stacked-upgrade`: 单张“威酷”卡的选卡表现、100 阳光种植、同格 C→B→A 叠种规则及车库等级门槛。

### Modified Capabilities

无。项目当前没有已建立的主规格。

## Impact

- UI：新增车库 Dialog/Widget、主界面入口、按钮、文本和车库背景/面板资源；布局以 800×600 逻辑画布适配现有界面体系。
- 玩家档案：`PlayerInfo` 增加车辆永久进度并升级存档版本；读取旧版本时将威酷初始化为 C，不改变旧金币和其他购买记录。
- 金币持久化：当前读档后强制把余额重置为 10,000,000 显示金币的测试逻辑必须改为“仅新建/重置档案设置初始余额”，否则 500,000 改装费用无法真实保存。
- 选卡与种植：调整 `SeedChooserScreen`、`LawnApp::HasSeedType`、`Board::CanPlantAt`、实际种植替换流程、卡片名称/费用/冷却和相关提示。
- 既有 WEIKU 链路：继续复用 C/B/A 的 `SeedType`、Reanimation、Projectile 和独立配置；集中车辆等级定义负责从当前等级解析下一等级。
- 资源与构建：增加车库资源清单和字符串；继续遵守非宽字符构建限制，首期运行文本使用 ASCII 安全资源键，中文显示需依赖既有字符串/字体能力。
- 兼容性：不得重排已有 `SeedType`；旧战斗存档中的 WEIKU_B/A 实体仍需按原等级恢复和运行。
